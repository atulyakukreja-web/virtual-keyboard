# KeyFlow — Virtual Keyboard (Task 13)

## Project Description
A web-based virtual keyboard that allows users to type text by clicking on on-screen keys. It is built using HTML, CSS and JavaScript with interactive key functionality.

## Features
- Fully interactive on-screen QWERTY keyboard
- Click keys to type into the editor
- Backspace, Enter, Tab and Space functionality
- Shift key for uppercase and symbols
- Caps Lock functionality
- Ctrl and Alt interactive feedback
- Physical keyboard synchronization
- Active key visual feedback
- Live character count
- Live word count
- Clear text button
- Responsive layout
- No backend required

## How to Run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or another modern browser.
3. Click the virtual keys or use the physical keyboard.
4. Type in the editor and use Clear to remove the text.

## Technologies
HTML5, CSS3 and JavaScript.
